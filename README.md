# Roguelike Dungeon Crawl

一款使用 Unity 制作的 2D 俯视角动作 Roguelike 原型。玩家在地牢中移动、射击、清理房间，获取随机道具组成构筑，击败每层 Boss 后继续深入地牢。

项目目前为**可玩原型**，包含完整的 6 层流程、程序化地牢、六套楼层主题、多种敌人与 Boss、37 件自动触发的被动道具、八件可切换武器，以及商店、宝箱、秘密房和挑战房。

## 游戏特色

- **程序化地牢**：每个种子生成不同的房间布局，支持 15×9、17×9、19×9、15×11、17×11、19×11 六种房间外框。
- **房间与探索**：起点房、战斗房、商店、宝箱房、秘密房、挑战房和 Boss 房。
- **六层小怪编成**：共 31 种实际入池小怪；前三层各 6 种，下水道、遗迹、黑曜另有独立编成，覆盖近战、远程、冲锋、区域和召唤机制。
- **六套主题 Boss**：食人魔、大僵尸、大恶魔，以及第 4-6 层专属的下水道巨魔、遗迹魔像、黑曜君王；每套都有不同的形象与招式组合。
- **精英怪**：15% 概率出现，2 倍血量、1.2 倍攻击，带金色描边与光效，必掉 1 金币。
- **连续撞击保护**：3 秒内受到 3 次敌人接触伤害后，进入 3 秒无敌并可穿过敌人，避免被堵在墙角连续受击。
- **子弹光效**：玩家眼泪与敌方/Boss 弹幕带有跟随本体颜色同步的柔光光晕。
- **武器系统（MVP）**：八件可切换武器 + 双武器槽：
  - 泪滴：无限弹药的基础自动弹丸
  - 绿宝石法杖：穿透能量球
  - 突击步枪：18 发弹匣、自动连射
  - 武士刀：前方扇形三段斩，第三段强化
  - 霰弹枪：6 发散射弹丸，6 发弹匣
  - 十字弩：高伤害穿透弩箭，5 发弹匣
  - 烈焰法杖：火焰球命中后产生小范围爆炸
  - 战斧：360° 全周旋斩，二段强化重击与高击退

  每层起点房会出现一件未持有武器，靠近按 `E` 装备；道具的加伤、射速、多发、穿透等修饰会应用到所有远程武器上。
- **武器获取闭环**：商店固定上架 **1 把武器 + 2 件道具**，武器按稀有度定价，靠近按 `E` 购买；宝箱房有 35% 概率给出武器；Boss 首杀必掉一把未持有武器。商店按 `F` 刷新时，未购买的武器货架也会一起刷新。
- **自动道具构筑**：37 件永久被动道具，围绕眼泪、爆炸、毒、暴击、分裂、光环、弹跳和击杀联动等机制产生组合。
- **稀有度与商店刷新**：道具与武器按普通/稀有/传说权重抽取；商店内可按 `F` 花费金币刷新未购买的商品，已购买栏位保持为空。
- **护盾系统**：初始 5 点护盾，优先吸收伤害，脱战 5 秒后每秒恢复 1 点。
- **楼层主题**：地牢、墓穴、炼狱、下水道、遗迹、黑曜六套地板/墙体/BGM，按楼层轮换。
- **难度成长**：敌人和 Boss 的血量、伤害、数量随楼层提升，第 6 层为最终层。
- **像素地牢 UI**：统一深色石质面板、金色描边与 Ark Pixel 中文像素字体；覆盖顶部状态栏、背包、Boss 血条、地图、商店/祭坛、暂停和结算界面；暂停菜单可调音乐与音效音量，设置会保存；新增“保存并返回主页”按钮，可随时把本局进度存到主菜单；失败/通关结算页提供“返回主页面”按钮。
- **启动主菜单**：运行游戏后先进入铺满整个画面的“地牢回响”标题页，使用自制的像素地牢入口背景、金色标题字、全屏边框、纹章和九宫格按钮；可开始游戏、局外成长、查看操作说明或退出。开始前时间冻结、玩家与 HUD 隐藏，按 `Enter` 或点击“开始游戏”后才进入第 1 层。存在单局存档时，主按钮变为“继续游戏”，并额外显示“新游戏”。
- **单局存档与继续**：暂停菜单点击“保存并返回主页”后，会写入 `Application.persistentDataPath/run_save.json` 并回到标题页；再次点击“继续游戏”可按相同种子重建地牢，恢复楼层、金币、生命/护盾、道具、双武器槽与弹药、当前房间、已探索/已清空/已领取房间状态、Boss 传送门和起始房武器架。退出游戏后重新启动也能继续。新游戏、死亡、通关或换层会清除旧单局存档。
- **局外金币**：死亡或通关时，本局剩余金币会 100% 存入局外金库并持久化保存；主菜单显示局外金币总数，结算页显示本局带出数量。存档位于 `Application.persistentDataPath/meta_progression.json`，后续角色、皮肤与武器解锁共用这份存档和消费接口。
- **放射状技能树**：主菜单“局外成长”打开，中心冒险者核心向外分出六条分支：生命、护盾、移速、伤害、金币、射速；每条两阶共 12 个节点。节点使用分支配色菱形、发光连线、同心导引环和悬停详情，花费局外金币永久激活，下一次开局时自动应用。
- **武器音效差异化**：八件武器拥有独立的发射/挥砍音效；武士刀三段斩与战斧二段旋斩另有终结技音效，近战连段之间也使用不同采样。
- **像素风素材**：0x72 地牢素材、Kenney 音效（RPG）、每件武器独立音效、CC0 背景音乐，以及项目自制图标。

## 操作方式

| 操作 | 按键 |
|---|---|
| 主菜单开始 / 继续 | `Enter` 或鼠标点击“开始游戏 / 继续游戏” |
| 移动 | `WASD` 或方向键 |
| 瞄准 / 射击 | 鼠标移动 / 按住鼠标左键 |
| 切换武器 | `Q`，或 `1` / `2` 直接选择槽位 |
| 装填步枪 | `R` |
| 装备武器 | 靠近起始房武器后按 `E` |
| 打开 / 关闭背包 | `B` |
| 查看地图 | 按住 `Tab` |
| 暂停 / 关闭界面 | `Esc` |
| 结算页返回主页 | 鼠标点击“返回主页面” |
| 购买商店武器 | 靠近武器货架按 `E` |
| 刷新商店 | 商店内按 `F` |
| 购买、拾取、菜单交互 | 鼠标左键 |

金币、红心等掉落物接触后自动拾取；宝箱房道具接触后免费获得；商店道具需要点击购买，商店武器货架靠近按 `E` 直接购买，商店内可按 `F` 花费金币刷新尚未购买的商品与武器；已购买的栏位会保持为空。每层起点房会出现一件当前未持有的武器，靠近后按 `E` 装备；宝箱房有概率给出武器，Boss 首杀必掉一把未持有武器；两个武器槽都满时会替换当前槽位。

调试快捷键（仅编辑器和开发版）：`F1` 到 `F6` 分别直接跳到第 1 到第 6 层，并自动补满全部道具；`F7` / `F8` / `F9` 分别直接获得法杖 / 步枪 / 武士刀，`F10` 重置为初始泪滴。若编辑器占用了功能键，请先点击 Game 视图再按。

## 游戏流程

1. 启动后进入主菜单，点击“开始游戏”或按 `Enter`。
2. 从起点房出发，先拾取本层提供的武器，再进入相邻房间。
3. 战斗房和挑战房会锁门，清空敌人后重新开门。
4. 每层包含商店、宝箱房、秘密房、挑战房和 Boss 房。
5. 击败 Boss 后出现传送门，进入下一层。
6. 第 6 层击败 Boss 直接通关；死亡则本局结束。
7. 结算时剩余金币进入局外金库；结算页点击“返回主页面”，之后从主页开始的新一局会按结果处理：通关保留道具与武器，死亡清空本局道具、武器与金币。
8. 局外金币可在“局外成长”技能树中激活永久强化；角色、皮肤与武器解锁后续接入。
9. 暂停菜单点击“保存并返回主页”会保存当前进度；之后可在标题页点击“继续游戏”，退出游戏后重新启动也能继续。

## 单局存档

- 存档文件：`Application.persistentDataPath/run_save.json`，与局外成长存档 `meta_progression.json` 分开。
- 保存时机：暂停菜单点击“保存并返回主页”。
- 恢复内容：楼层、地牢种子、金币、生命与护盾、道具、双武器槽/弹药/当前槽位、当前房间、已探索与已清空房间、已领取宝箱/已使用祭坛、Boss 传送门、起始房武器架。
- 不恢复：敌人当前血量、房间内未领取的临时掉落、商店当次货架；这些会在继续时按楼层重新生成，避免复制已消费奖励。
- 清除时机：开始新游戏、死亡、通关、进入下一层。

## 局外成长

主菜单点击“局外成长”打开放射状技能树。中心是冒险者核心，六条分支向外延伸；内环节点 20–25 金币，外环节点需要先激活同分支内环，费用 45–55 金币。

| 分支 | 内环 | 外环 |
|---|---|---|
| 生命 | 坚韧：最大生命 +1，20 金币 | 生命洪流：最大生命额外 +2，45 金币 |
| 护盾 | 壁垒：护盾上限 +1，20 金币 | 不破之盾：护盾上限额外 +2，45 金币 |
| 移速 | 疾行：移动速度 +4%，20 金币 | 风之步伐：移动速度额外 +6%，45 金币 |
| 伤害 | 锋锐：伤害 +5%，25 金币 | 破坏本能：伤害额外 +8%，55 金币 |
| 金币 | 贪婪：金币获取 +1，20 金币 | 点金术：金币获取额外 +2，50 金币 |
| 射速 | 迅捷：射击间隔 -3%，25 金币 | 连射：射击间隔额外 -5%，55 金币 |

技能树等级与局外金币保存在同一份 `meta_progression.json` 中，开局时自动应用到玩家属性。

## 房间类型

| 类型 | 说明 |
|---|---|
| 起点房 | 每层的初始位置，无战斗；中央下方提供一件未持有武器 |
| 战斗房 | 进入后锁门，清空敌人后开门 |
| 商店 | 上架 1 件未持有武器 + 最多 2 件未持有道具，使用金币购买 |
| 宝箱房 | 用眼泪击打宝箱 3 次后打开，随机获得一件道具，有 35% 概率改为武器 |
| 秘密房 | 中央祭坛，献祭 1 点生命换取一件未持有道具 |
| 挑战房 | 连续 3 波敌人，全部清空后奖励道具 |
| Boss 房 | 每层终点，击败后生成传送门，并必掉一把未持有武器（每次 Boss 一次） |

地图使用图标区分房间：

- 商店、宝箱房、Boss 房、已探索房间、未探索房间、起点分别使用独立图标。
- 已探索房间显示具体类型；相邻但尚未进入的房间显示问号；更远的房间保持隐藏。

## 数值规则

层数从 1 开始计算，最高 6 层。

| 项目 | 规则 |
|---|---|
| 普通敌人血量 | `基础血量 × (1 + 1 × 层数) × 精英倍率` |
| 精英倍率 | 血量 ×2 |
| 普通敌人攻击 | `基础伤害 + (层数 - 1)` |
| 精英攻击 | `ceil((基础伤害 + 层数加成) × 1.2)` |
| Boss 血量 | `40 × (1 + 0.50 × 层数)` |
| Boss 攻击 | `3 + (层数 - 1)` |
| 护盾 | 初始 5 点，脱战 5 秒后每秒 +1，上限 5 |
| 普通怪金币掉落 | 50% 概率 |
| 精英怪金币掉落 | 100% 掉落 1 枚 |

第 1 层 Boss 血量为 60，第 2 层为 80；Boss 的接触伤害、震地、弹幕和追踪弹共用同一套楼层伤害成长。

## 道具系统

所有道具都是**自动/永久被动**，不需要主动使用。道具通过背包、商店、宝箱和秘密祭坛获得。

代表性机制：

| 道具 | 效果 |
|---|---|
| 爆炸眼泪 | 眼泪首次命中时产生小范围爆炸 |
| 吸血鬼獠牙 | 每累计击杀 5 个敌人回复 1 点生命 |
| 弯勺魔咒 | 眼泪追踪附近敌人，伤害略微降低 |
| 腐蚀腺体 | 命中附加持续毒伤 |
| 尸爆菌 | 敌人死亡时产生范围爆炸 |
| 荆棘之心 | 玩家受伤时反击周围敌人 |
| 双生之眼 | 发数 +1，单发伤害降低 |
| 独眼巨人 | 伤害翻倍，射击间隔变长 |
| 裂体寄生虫 | 眼泪首次命中后分裂出小眼泪 |
| 神性微光 | 眼泪飞行时持续对周围敌人造成伤害 |
| 幽灵棱镜 | 眼泪获得穿透，速度提升 |
| 圣光帷幕 | 进入新房间时短暂无敌 |
| 弹跳泪滴 | 眼泪碰墙后反弹 2 次 |
| 血怒 | 生命越低伤害越高，最多 +2 |
| 收藏家之心 | 每持有 5 件道具伤害 +0.5，最多 +3 |
| 节拍器 | 每第 5 次射击额外发射 1 发 |
| 猎手之靴 | 击杀后 1.5 秒内移速 +30% |
| 杀戮余烬 | 每击杀 2 个敌人获得 0.8 秒无敌 |
| 守护之壳 | 只要有护盾，伤害只扣护盾，不会溢出扣血 |

完整道具定义位于 `Assets/Resources/Items`，共 37 件。

## 快速开始

1. 安装 **Unity 6000.3.5f2**（或兼容的 Unity 6 版本）。
2. 使用 Unity Hub 添加本项目文件夹。
3. 打开场景 `Assets/Scenes/SampleScene.unity`。
4. 点击 Play 开始游戏。

首次打开项目时需要等待 Unity 导入素材和编译脚本。项目启用了新 Input System，请确保 Project Settings 中的 Active Input Handling 为 **Input System Package (New)** 或 **Both**。

### 核心脚本

| 脚本 | 职责 |
|---|---|
| `DungeonGenerator` | 纯 C# 地牢拓扑生成，不依赖 GameObject |
| `DungeonBuilder` | 根据 `DungeonData` 实例化房间、门和装饰 |
| `DungeonFlowController` | 敌人生成、战斗激活、掉落、挑战房、楼层难度 |
| `RunManager` | 单局生命周期、死亡、通关、换层、重开、单局存档与继续 |
| `RunSaveService` | 单局进度 JSON 读写，位于 `persistentDataPath/run_save.json` |
| `PlayerController` | 移动与朝向 |
| `PlayerCombat` | 远程武器射击、武士刀近战、道具修正器联动 |
| `WeaponDefinition` | 单件武器的伤害、弹丸、弹匣、近战与手持表现配置 |
| `WeaponInventory` | 双武器槽、弹药、装填、切换与跨局重置 |
| `WeaponVisual` | 手持武器 Sprite 的瞄准跟随与朝向翻转 |
| `WeaponHud` | 右下角武器栏、弹药与装填进度 |
| `WeaponPickup` | 起始房武器架与 `E` 装备交互 |
| `PlayerHealth` | 生命、无敌帧、护盾与护盾恢复 |
| `PlayerInventory` | 永久道具、属性重建、拥有判定 |
| `CombatDebugHud` | 顶部状态栏、背包、提示、Boss 血条 |
| `MapUI` | Tab 地图、图标、探索可见性 |
| `RoomCamera` | 平滑跟随玩家、受击震动、换层对齐 |

## 编辑器工具

菜单路径：`Tools/Roguelike/`

| 命令 | 用途 |
|---|---|
| 构建地牢到当前场景 | 创建或复用 `Dungeon` 根对象并生成整层地牢 |
| 房间图生成器 | 打开可视化房间图窗口，查看种子拓扑 |
| 生成器压力测试 (500 seeds) | 批量验证连通性与种子可复现性 |
| DungeonBuilder 测试 | 校验墙体、门洞、碰撞与入口点 |
| 生成房间 Prefab | 重建 6 种尺寸的房间 Prefab |
| 生成战斗 Prefab | 重建敌人、Boss、眼泪、拾取物等 Prefab |
| 生成道具资产 | 重建 37 件道具定义与商店/祭坛 Prefab |
| 生成武器资产 | 重建泪滴、法杖、步枪、武士刀四件武器定义 |
| 生成楼层主题 | 重建六套楼层主题资产 |
| 创建玩家 | 创建玩家并自动绑定相机、背包、HUD、地图、武器和流程引用 |

如果场景中的玩家或房间引用丢失，可以按以下顺序重建：

```text
生成房间 Prefab → 生成战斗 Prefab → 生成道具资产 → 生成武器资产
→ 生成楼层主题 → 构建地牢到当前场景 → 创建玩家
```
