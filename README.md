# Roguelike Dungeon Crawl

一款使用 Unity 制作的 2D 俯视角动作 Roguelike 原型。玩家在地牢中移动、射击、清理房间，获取随机道具组成构筑，击败每层 Boss 后继续深入地牢。

项目目前为**可玩原型**，包含完整的 6 层流程、程序化地牢、三套楼层主题、多种敌人与 Boss、30 件自动触发的被动道具，以及商店、宝箱、秘密房和挑战房。

## 游戏特色

- **程序化地牢**：每个种子生成不同的房间布局，支持 15×9、17×9、19×9、15×11、17×11、19×11 六种房间外框。
- **房间与探索**：起点房、战斗房、商店、宝箱房、秘密房、挑战房和 Boss 房。
- **六种普通敌人**：追猎者、射击者、冲锋者、自爆史莱姆、亡灵法师、分裂僵尸。
- **三套主题 Boss**：食人魔、大僵尸、大恶魔，各自拥有不同的招式组合。
- **精英怪**：15% 概率出现，2 倍血量、1.2 倍攻击，带金色描边与光效，必掉 1 金币。
- **自动道具构筑**：30 件永久被动道具，围绕眼泪、爆炸、毒、暴击、分裂、光环等机制产生联动。
- **护盾系统**：初始 5 点护盾，优先吸收伤害，脱战 5 秒后每秒恢复 1 点。
- **楼层主题**：地牢、墓穴、熔岩三套配色与 BGM 循环，按楼层轮换。
- **难度成长**：敌人和 Boss 的血量、伤害、数量随楼层提升，第 6 层为最终层。
- **局内 UI**：顶部状态栏、护盾、金币、背包、Boss 血条、Tab 地图、暂停菜单。
- **像素风素材**：0x72 地牢素材、Kenney 音效、CC0 背景音乐，以及项目自制图标。

## 操作方式

| 操作 | 按键 |
|---|---|
| 移动 | `WASD` 或方向键 |
| 瞄准 | 鼠标移动 |
| 射击 | 按住鼠标左键 |
| 打开 / 关闭背包 | `B` |
| 查看地图 | 按住 `Tab` |
| 暂停 / 关闭界面 | `Esc` |
| 购买、拾取、菜单交互 | 鼠标左键 |

金币、红心等掉落物接触后自动拾取；宝箱房道具接触后免费获得；商店道具需要点击购买。

## 游戏流程

1. 从起点房出发，进入相邻房间。
2. 战斗房和挑战房会锁门，清空敌人后重新开门。
3. 每层包含商店、宝箱房、秘密房、挑战房和 Boss 房。
4. 击败 Boss 后出现传送门，进入下一层。
5. 第 6 层击败 Boss 直接通关；死亡则本局结束。
6. 通关后重新开始会保留已获得道具；死亡重开会清空道具与金币。

## 楼层主题

| 楼层 | 主题 | Boss 类型 | 主要招式 |
|---|---|---|---|
| 1 / 4 | 地牢 | 食人魔 | 三连冲锋、震地重击 |
| 2 / 5 | 墓穴 | 大僵尸 | 召唤骷髅、腐蚀扇形弹幕 |
| 3 / 6 | 熔岩 | 大恶魔 | 环形弹幕、螺旋弹幕、追踪弹 |

主题资产位于 `Assets/Resources/FloorThemes`，修改 `FloorTheme` 即可调整地板色、墙体色、相机背景和 BGM。

## 房间类型

| 类型 | 说明 |
|---|---|
| 起点房 | 每层的初始位置，无战斗 |
| 战斗房 | 进入后锁门，清空敌人后开门 |
| 商店 | 上架最多 3 件未持有道具，使用金币购买 |
| 宝箱房 | 用眼泪击打宝箱 3 次后打开，随机获得一件道具 |
| 秘密房 | 中央祭坛，献祭 1 点生命换取一件未持有道具 |
| 挑战房 | 连续 3 波敌人，全部清空后奖励道具 |
| Boss 房 | 每层终点，击败后生成传送门 |

地图使用图标区分房间：

- 商店、宝箱房、Boss 房、已探索房间、未探索房间、起点分别使用独立图标。
- 已探索房间显示具体类型；相邻但尚未进入的房间显示问号；更远的房间保持隐藏。

## 数值规则

层数从 1 开始计算，最高 6 层。

| 项目 | 规则 |
|---|---|
| 普通敌人血量 | `基础血量 × (1 + 1 × 层数) × 精英倍率` |
| 精英倍率 | 血量 ×2 |
| 普通敌人攻击 | `基础伤害 + (层数 - 1)` |
| 精英攻击 | `ceil((基础伤害 + 层数加成) × 1.2)` |
| Boss 血量 | `40 × (1 + 0.50 × 层数)` |
| Boss 攻击 | `3 + (层数 - 1)` |
| 护盾 | 初始 5 点，脱战 5 秒后每秒 +1，上限 5 |
| 普通怪金币掉落 | 50% 概率 |
| 精英怪金币掉落 | 100% 掉落 1 枚 |

第 1 层 Boss 血量为 60，第 2 层为 80；Boss 的接触伤害、震地、弹幕和追踪弹共用同一套楼层伤害成长。

## 道具系统

所有道具都是**自动/永久被动**，不需要主动使用。道具通过背包、商店、宝箱和秘密祭坛获得。

代表性机制：

| 道具 | 效果 |
|---|---|
| 爆炸眼泪 | 眼泪首次命中时产生小范围爆炸 |
| 吸血鬼獠牙 | 每累计击杀 5 个敌人回复 1 点生命 |
| 弯勺魔咒 | 眼泪追踪附近敌人，伤害略微降低 |
| 腐蚀腺体 | 命中附加持续毒伤 |
| 尸爆菌 | 敌人死亡时产生范围爆炸 |
| 荆棘之心 | 玩家受伤时反击周围敌人 |
| 双生之眼 | 发数 +1，单发伤害降低 |
| 独眼巨人 | 伤害翻倍，射击间隔变长 |
| 裂体寄生虫 | 眼泪首次命中后分裂出小眼泪 |
| 神性微光 | 眼泪飞行时持续对周围敌人造成伤害 |
| 幽灵棱镜 | 眼泪获得穿透，速度提升 |
| 圣光帷幕 | 进入新房间时短暂无敌 |

完整道具定义位于 `Assets/Resources/Items`，共 30 件。

## 技术栈

- **Unity**：6000.3.5f2
- **渲染**：URP 2D（Universal Render Pipeline 17.3.0）
- **输入**：新 Input System 1.17.0
- **语言**：C#
- **UI**：IMGUI（HUD、地图、背包、暂停菜单）
- **平台**：Windows（当前开发环境）

## 快速开始

1. 安装 **Unity 6000.3.5f2**（或兼容的 Unity 6 版本）。
2. 使用 Unity Hub 添加本项目文件夹。
3. 打开场景 `Assets/Scenes/SampleScene.unity`。
4. 点击 Play 开始游戏。

首次打开项目时需要等待 Unity 导入素材和编译脚本。项目启用了新 Input System，请确保 Project Settings 中的 Active Input Handling 为 **Input System Package (New)** 或 **Both**。

## 项目结构

```text
Assets/
├── Art/                     # 像素素材、自制图标
├── Editor/                  # 编辑器工具与资源工厂
├── Resources/
│   ├── Audio/               # 音效与 BGM
│   ├── Combat/              # 敌人、眼泪、拾取物 Prefab
│   ├── Dungeon/             # 房间 Prefab
│   ├── FloorThemes/         # 楼层主题资产
│   └── Items/               # 30 件道具资产、商店/祭坛 Prefab
├── Scenes/
│   └── SampleScene.unity    # 主场景
└── Scripts/
    ├── Audio/               # 音频服务与移动音效
    ├── Combat/              # 敌人、Boss、眼泪、HUD
    ├── Core/                # 局流程、地图、暂停、传送门
    ├── Dungeon/             # 地牢生成、房间、门、主题
    ├── Items/               # 道具定义、背包、属性、商店交互
    ├── Player/              # 玩家控制、战斗、生命、护盾、相机
    └── Visual/              # 精灵帧动画
```

### 核心脚本

| 脚本 | 职责 |
|---|---|
| `DungeonGenerator` | 纯 C# 地牢拓扑生成，不依赖 GameObject |
| `DungeonBuilder` | 根据 `DungeonData` 实例化房间、门和装饰 |
| `DungeonFlowController` | 敌人生成、战斗激活、掉落、挑战房、楼层难度 |
| `RunManager` | 单局生命周期、死亡、通关、换层、重开 |
| `PlayerController` | 移动与朝向 |
| `PlayerCombat` | 射击、眼泪修正器、道具联动 |
| `PlayerHealth` | 生命、无敌帧、护盾与护盾恢复 |
| `PlayerInventory` | 永久道具、属性重建、拥有判定 |
| `CombatDebugHud` | 顶部状态栏、背包、提示、Boss 血条 |
| `MapUI` | Tab 地图、图标、探索可见性 |
| `RoomCamera` | 平滑跟随玩家、受击震动、换层对齐 |

## 编辑器工具

菜单路径：`Tools/Roguelike/`

| 命令 | 用途 |
|---|---|
| 构建地牢到当前场景 | 创建或复用 `Dungeon` 根对象并生成整层地牢 |
| 房间图生成器 | 打开可视化房间图窗口，查看种子拓扑 |
| 生成器压力测试 (500 seeds) | 批量验证连通性与种子可复现性 |
| DungeonBuilder 测试 | 校验墙体、门洞、碰撞与入口点 |
| 生成房间 Prefab | 重建 6 种尺寸的房间 Prefab |
| 生成战斗 Prefab | 重建敌人、Boss、眼泪、拾取物等 Prefab |
| 生成道具资产 | 重建 30 件道具定义与商店/祭坛 Prefab |
| 生成楼层主题 | 重建地牢、墓穴、熔岩主题资产 |
| 创建玩家 | 创建玩家并自动绑定相机、背包、HUD、地图和流程引用 |

如果场景中的玩家或房间引用丢失，可以按以下顺序重建：

```text
生成房间 Prefab → 生成战斗 Prefab → 生成道具资产 → 生成楼层主题
→ 构建地牢到当前场景 → 创建玩家
```
